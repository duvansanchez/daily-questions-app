🔧 Test: Botones de Formato Corregidos

✅ Problemas Solucionados:
  1. Botones sin texto de ejemplo: Solo añaden los marcadores (** o *)
  2. Ctrl+Z funciona: No interceptamos atajos del sistema
  3. Cursor bien posicionado: Entre los marcadores cuando no hay selección
🧪 Casos de Prueba
1. Con texto seleccionado:
  1. Escribe: "texto importante"
  2. Selecciona "importante"
  3. Haz clic en B
  4. Resultado: "texto **importante**"
2. Sin texto seleccionado:
  1. Posiciona el cursor
  2. Haz clic en I
  3. Resultado: "**" (cursor entre asteriscos)
  4. Escribe tu texto
3. Atajos de teclado:
  • Ctrl+B - Negrita
  • Ctrl+I - Cursiva
  • Ctrl+S - Guardar
  • Ctrl+Z - Deshacer ✅
  • Ctrl+Y - Rehacer ✅
4. Botones de lista:
  • Tarea: Añade "- [ ] "
  • Viñeta: Añade "- "
Comportamiento Esperado:
  • Con selección: Aplica formato al texto seleccionado
  • Sin selección: Inserta solo los marcadores y posiciona el cursor entre ellos
  • Ctrl+Z/Y: Funciona normalmente para deshacer/rehacer
  • Otros atajos: Ctrl+A, Ctrl+C, Ctrl+V, etc. funcionan normalmente
