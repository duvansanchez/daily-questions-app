Objetivos Programados para Mañana

Funcionalidad completa para programar objetivos para el día siguiente y visualizarlos en una sección dedicada.

🚀 Funcionalidades Implementadas
✅ Base de Datos:
  • Nuevas columnas: fecha_programada DATE y programado_para NVARCHAR(20)
    Almacenan la fecha y tipo de programación
  • Migración ejecutada: Con verificación completa
    Incluye documentación de columnas
✅ Backend (API):
  • Nuevos endpoints:
    • GET /api/objetivos/programados/mañana - Lista objetivos programados
    • POST /api/objetivos/<id>/programar - Programa un objetivo
    • POST /api/objetivos/<id>/desprogramar - Quita la programación
  • Filtrado automático: Los objetivos programados para mañana no aparecen en la lista de hoy
    Consulta modificada con filtros de fecha
✅ Frontend:
  • Sección dedicada: "Objetivos Programados para Mañana" con contador
    Se muestra solo cuando hay objetivos programados
  • Botón de programar: 📅 en cada objetivo no completado
    Permite programar objetivos con un clic
  • Gestión completa: Programar, desprogramar y visualizar
    Interfaz intuitiva con confirmaciones
🧪 Cómo Probar
  1. Ve a la página de objetivos: Ir a Objetivos
  2. Busca un objetivo que no esté completado
  3. Haz clic en el botón 📅 "Programar para mañana"
  4. Verifica que aparezca el mensaje de confirmación
  5. Observa que el objetivo desaparece de la lista principal
  6. Verifica que aparezca la sección "Objetivos Programados para Mañana"
  7. En la sección de mañana, usa el botón ← para desprogramar
  8. Verifica que el objetivo vuelva a la lista principal
