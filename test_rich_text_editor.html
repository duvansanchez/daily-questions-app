🎯 Funcionalidades del Editor

  • Negritas: Usa **texto** o Ctrl+B
  • Cursivas: Usa *texto* o Ctrl+I
  • Resaltado: Usa ==texto==
  • Tareas: - [ ] para pendientes, - [x] para completadas
  • Listas: - para viñetas
  • Vista previa: Botón de ojo para ver el resultado
  • Auto-guardado: Se guarda automáticamente cada 2 segundos
  • Guardado manual: Ctrl+S o botón de disquete
