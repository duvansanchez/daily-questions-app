📝 Editor con Resaltado de Colores

Selecciona texto y elige un color del dropdown de resaltado.

  • Colores de resaltado

🎯 Instrucciones de Uso

  1. Selecciona texto en el editor
  2. Haz clic en el dropdown del resaltador (icono de marcador)
  3. Elige un color de la lista
  4. El texto se marcará con la sintaxis: ==color:texto==
  5. Usa "Vista previa" para ver el resultado renderizado
  6. Usa "Quitar resaltado" para eliminar el formato

📋 Sintaxis de Colores

  • ==yellow:texto== → texto amarillo
  • ==green:texto== → texto verde
  • ==blue:texto== → texto azul
  • ==red:texto== → texto rojo
  • ==orange:texto== → texto naranja
  • ==purple:texto== → texto morado
