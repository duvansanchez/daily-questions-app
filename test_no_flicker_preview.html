⚡ Test: Preview Sin Parpadeo

Problema Solucionado:

Eliminado el parpadeo al abrir el modo focus. Ahora inicia directamente en vista previa sin mostrar primero el modo edición.

Inicialización Instantánea
🔧 Cambio Técnico Implementado:
❌ Antes (Con Parpadeo):
// Inicializar en modo edición
setTimeout(() => {
  togglePreview(); // Cambiar a preview
}, 100);
Resultado: Se ve edición → preview (parpadeo)
✅ Después (Sin Parpadeo):
// Configurar directamente en preview
editorMode = 'preview';
textarea.style.display = 'none';
previewDiv.style.display = 'block';
renderizarPreview();
Resultado: Directamente en preview (sin parpadeo)
