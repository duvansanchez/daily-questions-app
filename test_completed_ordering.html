🧪 Test: Completed Subobjetivos Ordering

Test Instructions

  1. Open the main application at http://localhost:5000
  2. Login and go to the Objetivos section
  3. Create or open an objetivo with multiple subobjetivos
  4. Enter Focus mode for that objetivo
  5. Test the following scenarios:

🎯 Test Scenarios

Scenario 1: Initial Ordering

✅ Expected: All non-completed subobjetivos should appear first, followed by all completed ones

🔍 How to verify: Look at the subobjetivos list in focus mode

Scenario 2: Completing a Subobjetivo

✅ Expected: When you check a subobjetivo as completed, it should automatically move to the bottom

🔍 How to verify: Check a subobjetivo checkbox and observe it moves down

Scenario 3: Uncompleting a Subobjetivo

✅ Expected: When you uncheck a completed subobjetivo, it should move back up with the non-completed ones

🔍 How to verify: Uncheck a completed subobjetivo and observe it moves up

Scenario 4: Manual Reordering Restrictions

✅ Expected: You should NOT be able to move completed items above non-completed ones

✅ Expected: You should NOT be able to move non-completed items below completed ones

🔍 How to verify: Try using the up/down arrows in the action dropdown

Scenario 5: Button States

✅ Expected: Up/down buttons should be disabled when moves would violate the completion boundary

🔍 How to verify: Check if buttons are disabled appropriately in the action dropdown
