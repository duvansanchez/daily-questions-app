✅ Test: Botón de Tarea Corregido

🔧 Corrección Aplicada:
  • Antes: - [ ] Nueva tarea (añadía texto de ejemplo)
  • Ahora: - [ ] (solo el checkbox, listo para escribir)
🧪 Instrucciones de Prueba:
  1. Posiciona el cursor donde quieras añadir una tarea
  2. Haz clic en "Tarea" - Debería añadir solo - [ ]
  3. Escribe tu tarea después del checkbox
  4. Prueba "Viñeta" - Debería añadir solo -
✅ Comportamiento Esperado:
  • Solo añade el formato básico (checkbox o viñeta)
  • Te deja el cursor listo para escribir
  • No añade texto de ejemplo
  • Funciona en cualquier posición del texto
