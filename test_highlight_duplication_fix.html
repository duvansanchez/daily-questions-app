🔧 Test: Corrección de Duplicación de Resaltados

Problema Solucionado:

Los event listeners de resaltado ahora se configuran solo una vez usando delegación de eventos.

❌ Problema Anterior:

Los event listeners se agregaban cada vez que se abría el modal, causando múltiples ejecuciones: ==yellow:==yellow:==yellow:texto==

✅ Solución Implementada:

Event listeners globales con delegación que se ejecutan solo una vez: ==yellow:texto==

🧪 Instrucciones de Prueba:
  1. Selecciona texto en el editor
  2. Haz clic en "Resaltar" → Elige un color
  3. Verifica que solo se agregue una vez: ==color:texto==
  4. Usa "Vista Previa" para ver el resultado
  5. Repite varias veces para confirmar que no se duplica
🔧 Cambios Técnicos:
  • Event listeners movidos: Fuera de inicializarEditorNotas()
  • Delegación de eventos: Un solo listener en document
  • Prevención de duplicados: Se ejecutan solo una vez
  • Mejor rendimiento: Menos listeners en memoria
